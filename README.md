# NEON ARENA
A small browser-based top-down arcade survival game prototype.

## Run locally
Open `index.html` in a modern browser. For development, VS Code + Live Server is recommended. No build step or package install is required.

## Controls
- WASD: move
- Mouse: aim
- Left click: ranged attack
- Right click: directional melee
- Tab: switch Arc Pistol / Phase Scatter
- Space: dash
- Q: pulse ability
- Esc: pause

## Included in this starter
- Canvas rendering and smooth camera follow
- Custom procedural exo-suit player artwork
- Two switchable ranged weapon modes, melee and pulse ability
- Four enemy archetypes and endless spawning
- XP, level-up upgrade choices, survival timer and local best time
- Neon arena environment, particles and responsive HUD

## GitHub Pages
Push the repository to GitHub. In Settings → Pages, select Deploy from a branch, choose `main` and `/ (root)`, then save.
